💤 React Sleep Detector with Alarm System

This project is a React-based sleep detection system that uses the user’s webcam to monitor alertness and trigger an alarm sound when drowsiness is detected.

🔍 How It Works

The application accesses the webcam and captures live video frames.

Each video frame is drawn onto a canvas for pixel-level analysis.

The average brightness of each frame is calculated in real time.

A low brightness value is interpreted as eye closure or drowsiness.

When sleep is detected, a sound alarm is automatically triggered.

Users can upload a custom alarm sound directly from their system.

🎯 Key Features

Real-time webcam access

Frame-by-frame canvas processing

Brightness-based sleep detection logic

Audio alert system for wake-up notification

Custom alarm sound upload support

Built using React with modern hooks (useState, useEffect, useRef)

⚠️ Note

This project is a prototype/demo implementation intended for academic and learning purposes. For production-level accuracy, advanced eye-tracking or machine learning models can be integrated.
